# AI Prompt Template

## Overview
Use this template to structure prompts for LLMs like Grok or ChatGPT. Clear sections improve response accuracy and consistency.

## Task Description
- Define the main objective here.
- Example: Generate a blog post on AI ethics.

## Input Data
- Provide any necessary data or context.
- Example: Key points: privacy, bias, transparency.

## Constraints
- List limitations (e.g., word count, style).
- No more than 500 words.
- Use formal language.

## Output Format
- Specify the desired structure.
- Start with an introduction, followed by body paragraphs, and end with a conclusion.

## Examples
### Input Example
Task: Summarize a news article.
Input: [Paste article text]

### Output Example
Summary: The article discusses...

## Tips
- Iterate based on AI feedback.
- Use bold **key terms** for emphasis.
