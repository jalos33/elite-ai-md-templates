# Contribution Guide

## How to Contribute
1. Fork the repo.
2. Create a branch: git checkout -b feature/new-md.
3. Add your changes.
4. PR with description.

## What to Contribute
- New .md templates for AI.
- Improvements to existing files.
- Bug fixes in examples.

## Standards
- Follow Style-Guide.md.
- Test AI compatibility.

## Review Process
- PRs reviewed within 48 hours.
- Merge if approved.

## Thanks
Contributors get credited in README.md!
