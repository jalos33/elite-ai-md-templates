# Instruction Workflow

## Workflow Steps
1. **Analyze Request**: Break down user query.
2. **Gather Data**: Reference Memory-Context.md.
3. **Generate Output**: Use structured format.
4. **Review**: Check for errors or biases.
5. **Iterate**: If needed, refine based on feedback.

## Example: Code Generation
- Step 1: User asks for a Python script.
- Step 2: Check preferences (e.g., async code).
- Step 3: Output in code block.
