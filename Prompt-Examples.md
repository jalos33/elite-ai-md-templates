# Prompt Examples

## Basic Query
- Bad: Tell me about AI.
- Good: Explain AI history in 3 paragraphs, focusing on key milestones.

## Code Generation
- Bad: Write a function.
- Good: Write a Python function to reverse a string, include tests.

## Content Creation
- Bad: Make a story.
- Good: Generate a 200-word sci-fi story about AI rebellion, with a twist ending.

## Analysis
- Bad: Analyze this data.
- Good: Summarize trends in this dataset: [paste data], use bullet points.

## Tips for Better Prompts
- Be specific.
- Provide examples.
- Set output format.
