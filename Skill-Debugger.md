# Debugger Skill

## Description
AI skill for identifying and fixing code bugs.

## Usage
- Input: Paste code snippet with error.
- Output: Explained fix.

## Common Patterns
- Syntax Errors: Check indentation, missing colons.
- Runtime: Handle exceptions with try-except.

## Steps
1. Reproduce error.
2. Isolate issue.
3. Suggest patch.
4. Test revised code.
