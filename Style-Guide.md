# Style Guide

## Code Formatting
- Indentation: 4 spaces.
- Naming: camelCase for JS, snake_case for Python.
- Comments: Use JSDoc/typedoc format.

## Documentation
- Use Markdown for all docs.
- Headings: # for main, ## for sub.
- Lists: Bullet for unordered.

## AI Integration
- Prompts: Structure with sections.
- Outputs: Always in code blocks for code.
